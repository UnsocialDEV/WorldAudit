[CENTER][SIZE=6][B]WorldAudit[/B][/SIZE]
[I]Server-side block, container, lookup, and rollback auditing for Vintage Story.[/I][/CENTER]

[B]WorldAudit[/B] records what changed in your world, who changed it, what caused it, and gives admins the tools to inspect history, investigate griefing, preview rollbacks, restore changes, and apply fixes safely.

[B]Support Discord:[/B]
[URL=https://discord.gg/5365aHU7rt]https://discord.gg/5365aHU7rt[/URL]

[HR][/HR]
[SIZE=5][B]Features[/B][/SIZE]

[LIST]
[*][B]Server-side auditing[/B] - runs on the server and stores audit data in SQLite.
[*][B]Block history[/B] - records block placement, breaking, and other block mutations with actor, cause, action, before/after block codes, and timestamps.
[*][B]Container history[/B] - records container transactions with before/after inventory snapshots and per-slot deltas.
[*][B]Inspect mode[/B] - interact with a block or container in-game to see its recent history immediately.
[*][B]Lookup tools[/B] - search audit history around your position with time, radius, user, cause, action, and code filters.
[*][B]Rollback preview jobs[/B] - build rollback plans before applying anything to the world.
[*][B]Restore preview jobs[/B] - rebuild changes from history when you want to put something back.
[*][B]Undo jobs[/B] - generate a new job that inverts a completed rollback or restore.
[*][B]Incremental apply[/B] - applies rollback and restore jobs over future ticks instead of trying to do everything at once.
[*][B]Synthetic re-audit[/B] - rollback and restore changes are logged too, so admin actions remain auditable.
[*][B]Maintenance tools[/B] - includes retention, purge, WAL checkpointing, optimize, queue status, and consumer pause/resume controls.
[/LIST]

[HR][/HR]
[SIZE=5][B]What Gets Logged[/B][/SIZE]

[LIST]
[*]Who made the change
[*]What action happened
[*]The suspected cause when available
[*]The time of the change
[*]The position of the change
[*]The old and new block state
[*]Block entity snapshots when relevant
[*]Container item movements and slot-level changes
[/LIST]

[HR][/HR]
[SIZE=5][B]How To Install[/B][/SIZE]

[LIST]
[*]Install the mod on the server.
[*]Start the server once so the config file is generated.
[*]Adjust [B]worldaudit.json[/B] if you want to change database path, page size, retention, rollback speed, or enable/disable capture systems.
[*]Make sure the admins or moderators who need it have permission to use the commands.
[/LIST]

[B]Side:[/B] Server only

[HR][/HR]
[SIZE=5][B]How To Use[/B][/SIZE]

[B]1. Inspect a block or container[/B]
[LIST]
[*]Use [B]/wa inspect[/B] to toggle inspect mode on.
[*]Then interact with a block or container in the world.
[*]WorldAudit will show the recent history for what you clicked, opened, used, or broke.
[*]Use [B]/wa inspect[/B] again to turn inspect mode off.
[/LIST]

[B]2. Search nearby history[/B]
[LIST]
[*]Use [B]/wa near[/B] to search around your current position using the configured default radius.
[*]Use [B]/wa lookup[/B] when you want more control over filters.
[/LIST]

[B]3. Preview a rollback[/B]
[LIST]
[*]Use [B]/wa rollback[/B] with filters to create a preview job.
[*]Review the created job before applying it.
[*]When you are satisfied, run [B]/wa apply &lt;jobId&gt;[/B].
[/LIST]

[B]4. Preview a restore[/B]
[LIST]
[*]Use [B]/wa restore[/B] with filters to create a restore preview job.
[*]Apply it later with [B]/wa apply &lt;jobId&gt;[/B].
[/LIST]

[B]5. Undo an admin action[/B]
[LIST]
[*]Use [B]/wa undo &lt;jobId&gt;[/B] to create a new preview that reverses a completed rollback or restore job.
[*]Apply that new job if needed.
[/LIST]

[B]6. Review jobs and system state[/B]
[LIST]
[*][B]/wa jobs[/B] shows recent rollback and restore jobs.
[*][B]/wa job &lt;jobId&gt;[/B] shows one job in detail.
[*][B]/wa status[/B] shows queue, rollback, database, and maintenance status.
[/LIST]

[HR][/HR]
[SIZE=5][B]Command Reference[/B][/SIZE]

[LIST]
[*][B]/wa inspect[/B] - Toggle inspect mode. Interact with a block or container to view history.
[*][B]/wa lookup [filters][/B] - Search audit history around your current position.
[*][B]/wa near [filters][/B] - Search nearby history using the configured default radius.
[*][B]/wa rollback [filters][/B] - Create a rollback preview job.
[*][B]/wa restore [filters][/B] - Create a restore preview job.
[*][B]/wa undo &lt;jobId&gt;[/B] - Create a preview job that reverses a completed job.
[*][B]/wa apply &lt;jobId&gt;[/B] - Queue a preview job for execution.
[*][B]/wa jobs[/B] - List recent jobs.
[*][B]/wa job &lt;jobId&gt;[/B] - Show one job in detail.
[*][B]/wa status[/B] - Show runtime, queue, maintenance, and rollback status.
[*][B]/wa reload[/B] - Reload the config and rebuild runtime services.
[*][B]/wa consumer pause[/B] - Pause database consumption.
[*][B]/wa consumer resume[/B] - Resume database consumption.
[*][B]/wa purge t:&lt;age&gt;[/B] - Preview a purge by age.
[*][B]/wa purge confirm t:&lt;age&gt;[/B] - Execute the purge.
[/LIST]

[HR][/HR]
[SIZE=5][B]Filter Syntax[/B][/SIZE]

These filters can be used with lookup, near, rollback, and restore commands:

[LIST]
[*][B]t:&lt;time&gt;[/B] - time range
[*][B]r:&lt;radius&gt;[/B] - search radius
[*][B]u:&lt;user|#cause&gt;[/B] - player name or cause
[*][B]a:&lt;action&gt;[/B] - block action
[*][B]i:&lt;codes&gt;[/B] - include block codes
[*][B]e:&lt;codes&gt;[/B] - exclude block codes
[*][B]-b[/B] - exclude block history
[*][B]-c[/B] - exclude container history
[/LIST]

[B]Example ideas:[/B]
[LIST]
[*][B]/wa near t:1d[/B] to review recent nearby changes
[*][B]/wa lookup u:PlayerName r:10[/B] to review one player in a specific area
[*][B]/wa rollback t:2h u:PlayerName[/B] to preview rolling back a player's recent changes
[*][B]/wa restore t:30m r:5[/B] to preview restoring recent changes in a small area
[/LIST]

[HR][/HR]
[SIZE=5][B]Configuration Highlights[/B][/SIZE]

WorldAudit creates a [B]worldaudit.json[/B] config file. Important options include:

[LIST]
[*]Database path
[*]Writer batch size and flush timing
[*]Default page size
[*]Default near radius
[*]Rollback preview limit
[*]Rollback blocks processed per tick
[*]Retention days
[*]Checkpoint and optimize intervals
[*]Enable or disable block audit
[*]Enable or disable container audit
[*]Enable or disable natural/system cause providers
[*]Verbose diagnostics logging
[/LIST]
